###Guidelines

Name files with timestamp and a short description: YYYY-MM-DD_HHMMSS-description.ipynb (or .md)
Keep one experiment per file when possible.
Include links to data paths (data/raw/...) and scripts used.
Example filenames

notebooks/2026-07-12_143000-EM-preprocessing.ipynb
notebooks/2026-07-12_150500-microscope-calibration.md
Recommended front matter for each notebook/MD file

Date/Time, Author (DMugdha), Experiment ID
Purpose, Materials, Commands to reproduce, Data provenance EOT
